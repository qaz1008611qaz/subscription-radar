# 订阅雷达 Subscription Radar
上传账单 / 截图 / 邮件 → 自动识别订阅 → 续费前 3 天提醒。
由 Devin Bot 协作开发，7 天交付第一版。

## 技术栈
- 后端：Python 3.11 + FastAPI + SQLite
- 解析：pdfplumber（PDF）、PaddleOCR（截图）、邮件转发解析
- 前端：Next.js
- 提醒：定时任务 + 邮件 / Telegram

## 排期
- Day 1-2：解析流程 + 样本测试
- Day 3-4：订阅识别
- Day 5：续费提醒
- Day 6-7：界面、部署、公开
 ## 数据隐私
- 原始账单只在服务端解析，解析完立即删除，最多保留 24 小时
- 传给大模型前先脱敏：卡号只保留后 4 位，姓名、手机号、邮箱、地址、证件号一律打码
- 大模型只拿到 商户 / 金额 / 日期 三个字段
- Devin Bot 开发时只用 /samples 里的合成假账单，不接触真实用户数据
- 密钥放在 Devin Secrets 和环境变量里，不写进 prompt 和代码
- 数据库加密存储，用户可以一键删除全部数据
- CI 自动扫描日志和 prompt，发现敏感信息就让测试失败
